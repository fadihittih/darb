### Design specificity verdict

Specific to this product: the colour-coded day cards, the per-day "Why it breaks" box with an evidence date, the JOD Pass table and the route map could not be reused by an unrelated product unchanged. The page follows Figma 03 block for block (stepper, title + counts, score card top right, day cards left, map / Pass / dark Fix-all card right). Detector: only `overused-font` (Figma-mandated) in the CLI scan; the overlay adds `cramped-padding` (stepper pill), `line-length` (why-box) and `first-viewport-column-overflow` (the two-column layout itself) — all consequences of the Figma layout.

### What's working

- The score card, counts pills and coloured card borders give the verdict in one glance, and colour is never alone (✕ / ! / ✓ glyphs).
- The why-box quotes the evidence date ("checked 24 Sep 2026"), which carries the honesty rule into the UI.
- Mobile keeps the Days / Map tabs (§6b) and a sticky Fix-all bar.
